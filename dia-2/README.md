# Día 2: ejercicio educativo

Ejecutar `cargo test` desde esta carpeta después de instalar el toolchain y dependencias indicados en el README raíz. El código inicial de `set_whitelist` omite autorización como parte del ejercicio; identificar y resolver el problema es trabajo del alumno. Una prueba que descubre ese fallo no se debe silenciar como si el contrato fuera seguro.

La solución final se revisa en `../dia-3/`, que es un crate separado. No usar esta base educativa con fondos reales. Este documento no cambia el ejercicio ni atribuye el scaffold a una implementación original del alumno.
